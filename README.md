# Dark Skull Corporation

Dark Skull Corporation (DSC) is an independent software and game development brand focused on building applications, games, and digital products.

## About

Dark Skull Corporation develops software products and interactive experiences with a focus on practical functionality, clean design, and continuous improvement.

This repository contains the source code for the official Dark Skull Corporation website.

## Development Principles

When working on DSCWeb:

- Preserve existing functionality.
- Avoid unnecessary rewrites.
- Keep the interface organized.
- Reuse existing components where possible.
- Maintain responsive behavior.
- Avoid duplicated logic.
- Test changes before deployment.
- Remove obsolete references when features are permanently removed.
- Keep sensitive configuration outside the repository.

## Security

Never commit sensitive information to the repository.

This includes:

- API keys
- Passwords
- Database credentials
- Access tokens
- Private keys
- Production secrets
- Environment files containing secrets

Use environment variables or secure deployment configuration for sensitive information.

## Development Workflow

A typical development workflow is:

1. Make the required changes.
2. Test the website locally.
3. Verify navigation and functionality.
4. Check desktop and mobile layouts.
5. Review the changes.
6. Commit the changes.
7. Push to the repository.
8. Deploy the updated version.
